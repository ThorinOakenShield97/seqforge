# SeqForge

> A modern Python toolkit for biological sequence analysis.

SeqForge is an open-source command-line toolkit designed to simplify common bioinformatics tasks involving **FASTA** and **FASTQ** files.

The project focuses on providing fast, reliable and well-documented utilities for biological sequence processing while following modern software engineering practices.

---

## ✨ Features

Current and planned features include:

- FASTA and FASTQ parsing
- Sequence statistics
- GC content calculation
- Sequence length analysis
- Sequence filtering
- Reverse complement generation
- DNA → Protein translation
- Motif search
- File validation

## 📖 Quick Example

```bash
seqtool stats genome.fasta

seqtool gc genome.fasta

seqtool filter genome.fasta --min-length 500

seqtool translate gene.fasta
```

## 🎯 Project Goals

SeqForge aims to:

- provide intuitive command-line utilities
- produce reproducible results
- follow modern Python best practices
- maintain excellent documentation
- remain lightweight and modular

---

## 🧬 Philosophy

SeqForge follows one simple idea:

> **Do one thing and do it well.**

Each command performs one task with a consistent interface and predictable behaviour.
